二、后端多模块单体架构
----------------------

                         ┌──────────────────────────────┐
                         │ trade-app                    │
                         │ - Spring Boot 启动和模块组装 │
                         │ - 配置、健康检查和异常处理   │
                         └──────────────┬───────────────┘
                                        │
             ┌──────────────────────────┼──────────────────────────┐
             │                          │                          │
             ▼                          ▼                          ▼
┌────────────────────────┐  ┌────────────────────────┐  ┌────────────────────────┐
│ trade-market           │  │ trade-watchlist        │  │ trade-strategy         │
│ - 股票身份与 K 线      │  │ - 默认股票与自选股     │  │ - 策略规则与回测契约   │
│ - 行情缓存与刷新       │  │ - PostgreSQL / MyBatis │  │ - 可解释决策模型       │
│ - REST / WebSocket     │  │ - REST API             │  │                        │
└────────────▲───────────┘  └────────────┬───────────┘  └────────────┬───────────┘
             │                           │                           │
             └───────────────────────────┴───────────────────────────┘
                         watchlist 和 strategy 依赖 market

                         ┌──────────────────────────────┐
                         │ trade-research               │
                         │ - 申万行业和成分股           │
                         │ - 预告、快报和正式财报       │
                         │ - 单季度与盈利质量计算       │
                         │ - 全年利润三情景预测         │
                         │ - 预测 PE 和五档估值         │
                         │ - 综合预期差排序             │
                         │ - DeepSeek 全量PE复核与证伪  │
                         │ - PostgreSQL 任务快照        │
                         └──────────────▲───────────────┘
                                        │
                                        └── 依赖 trade-market

模块依赖方向：

trade-app -> trade-market
trade-app -> trade-watchlist -> trade-market
trade-app -> trade-strategy  -> trade-market
trade-app -> trade-research  -> trade-market

规则：

1. 所有模块最终打包进 trade-app，一个进程运行。
2. Maven 模块依赖必须保持单向、无循环。
3. 业务模块拥有自己的 Controller、Service、Repository、Client、DTO 和资源。
4. trade-market 不得反向依赖其他业务模块。
5. 财报数字、预测、估值和评分由版本化程序规则计算。
6. AI 不得修改计算结果，只能补充解释、风险和证伪条件。
